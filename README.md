# judepolsonphotography

The website for Jude Polson, photographer.

Astro 7, static output, deployed to Cloudflare Workers.

```bash
npm install
npm run dev      # local preview at localhost:4321
npm run build    # production build into dist/
```

**Working on this site?** Read `CLAUDE.md` first — it points to everything
else. Adding photographs is covered in `docs/content-model.md`.
